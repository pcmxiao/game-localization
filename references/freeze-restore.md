# 控制码冻结与还原

翻译文本送出去之前，把所有引擎语法换成占位符；译文回来之后再换回去。
**机器看不到占位符，就不会弄坏它。**

## 通用流程

```
原文 ──freeze──▶ 占位符版 ──翻译──▶ 译文占位符版 ──restore──▶ 最终文本
                    │                                    │
              多重集记下来 ◀────── 等值校验 ◀──────────┘
```

**校验 = 占位符多重集必须完全相等。**
少一个 `\N[1]` 或多写一个，游戏会在奇怪的地方崩 —— 表情不切、名字不显示、
变量显示成空白。

本仓库的 `apply_sheet.py` 实现了这一层：抽取时统计每条原文的控制码多重集，
写回前比对照文，**不通过的条目跳过并列出，不硬写**。

## 各引擎语法表

### RPG Maker MV / MZ

| 语法 | 含义 |
|---|---|
| `\V[n]` | 变量值 |
| `\N[n]` | 角色名 |
| `\C[n]` | 颜色 |
| `\I[n]` | 道具图标 |
| `\P[n]` / `\$G` / `\G` | 货币 |
| `\.` `\|` `\^` | 等待 / 继续 / 延后 |
| `\{` `\}` | 字体 / 颜色控制 |
| `%1` `%2` | 插件参数占位符，数据库 `message` 字段常见 |

**带表情差分 / 立绘插件的 RPG 额外**：

| 语法 | 含义 | 实测频次 |
|---|---|---|
| `\m[n]` | 表情差分 | 18427 |
| `\z[n]` | 立绘姿态切换 | 18427 |
| `\ac\…\xxx\}` | 插件命令块（含闭合标签） | 709 |
| `\item[n]` | 道具名 | 363 |
| `\N[n]` | 说话人 | 5580 |
| `\V[n]` | 变量 | 501 |
| `\{` `\}` | 颜色/字体控制 | 131 / 15 |

合计 44,158 处，其中 `\m` + `\z` 占 **83%**。

> 这就是通用保护方案不够用的原因：它们只认 `\V \C \N \I`，
> 恰好漏掉了占比最大、改错必崩的两类。
> 本仓库的正则 `\\(?:[A-Za-z]+|\d|\{|\[|[^\w\s{])` 覆盖全部。

`\ac\` 块的内容**常常本身就是文本**，处理方式和外面不同 ——
先读懂插件在做什么，再决定翻不翻里面。

### Ren'Py

markup 是 `{tag}` 形式：

```
{i}待って{w=0.4}、行かないで{/i}
▶ [[R0]]待って[[R1]]、行かないで[[R2]]
```

注意冻结后的占位符**出现在句子中间**，不是在句子外围包裹。

- `{i}` `{b}` `{u}` `{s}` `{p}` `{w=0.4}` `{color=#fff}` `/`（停顿）`\n`
- 变量 `[variable]`、插值 `[expr]`、`%%` 转义
- 行尾说话人 `[name]`（需启用 `speaker` 扩展）

### TyranoScript / KAG

```
[mark color=#ff0000]台词[/mark]
[link target=xxx]选项[/link]
[s]跳到[/s][l][p]
```

危险的是**参数里也含文本**：`[cm name="三个字"]`。
翻 `name` 的值可以，翻 `target` 绝对不行。

### gettext (.po)

- 结构行（`#:` `#.` `#|`）不要动
- `msgid_plural` 与 `msgstr[n]` 的条数要对齐
- `\n` 是结构的一部分，不能吞
- `fuzzy` 条目通常还没确认

### NScripter

`#` 开头是命令，`*` 开头是标签，都不能翻。

### Unity

- TextMeshPro 富文本：`<sprite=0>` `<color=#fff>` `<size=80%>` `<br>`
- `\uXXXX` 转义、`\n`
- **不要动** `.meta` 的 GUID、`m_Name`、脚本类型名

### Godot

- `.tscn` 里的 `[sub_resource]` 引用名 —— 改了会断引用
- `StringName` / `NodePath`

### Unreal

- `FText` 表的 key 不翻，只有 value 翻
- `<...>` 富文本、`\n`

## 通配符 / 占位符（跨引擎）

任何引擎都可能有：

| 形式 | 例子 |
|---|---|
| printf | `%s` `%d` `%1$s` `%02d` |
| Python | `{name}` `{0}` `%(name)s` |
| ICU | `{count, plural, one{...} other{...}}` |
| Rust | `{0}` |
| 自定义 | `[[R#]]` `<<TAG>>` `[param]` |

> ⚠️ `{i}` 在 Ren'Py 是 markup，在 Python 脚本里是格式化占位符 ——
> 语义完全不同，别混。同一个字符在不同上下文可能是三种东西。

## 还原时的三个检查

1. **多重集相等** —— 一个不多一个不少
2. **顺序合理** —— 有些语法要求配对顺序（如 `\ac\` 与 `\xxx\}`）
3. **原文仍可定位** —— 还原后拿回原串去游戏里搜，能搜到
